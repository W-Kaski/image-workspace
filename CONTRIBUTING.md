# Contributing

## Scope

This repository is a consolidated full-stack project. Prefer changes that keep frontend, backend, and docs aligned.

## Expectations

- Keep naming consistent with `Image Workspace` at the repo/documentation level.
- Avoid broad Java package renames unless they are explicitly planned.
- Update README or docs when changing setup, paths, or public-facing behavior.
- Do not remove historical artifacts without confirming they are no longer needed.

## Good contribution targets

- developer setup improvements
- frontend/backend documentation alignment
- safer upload and permission flows
- tests around stable service behavior
- performance or analytics clarity improvements
