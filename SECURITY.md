# Security Policy

## Supported use

This repository is a portfolio and engineering-learning project. It should not be treated as production-hardened software.

## Reporting

If you find a security-sensitive issue, avoid posting secrets or exploit details publicly. Share a minimal reproduction or affected area through a private channel if available.

## Sensitive material to avoid committing

- cloud access keys
- database credentials
- Redis credentials
- local machine paths
- private media assets
